# CodeClass

Личный кабинет репетитора по информатике: ученики подключаются по коду, преподаватель планирует занятия и прикладывает домашние задания и материалы.

## Быстрый запуск

1. При необходимости скопируйте `.env.example` в `.env` и смените пароль преподавателя.
2. Запустите приложение:

   ```bash
   docker compose up --build
   ```

3. Откройте [http://localhost:8080](http://localhost:8080).

Значения по умолчанию для первого входа преподавателя:

- логин: `teacher`
- пароль: `change-me-now`
- код подключения: `teacher_code`

Перед использованием обязательно задайте собственный `TEACHER_PASSWORD` в `.env`. Отображаемое имя и код подключения можно изменить в кабинете.

## Разработка

Понадобятся Java 21+, Maven и PostgreSQL. Параметры подключения и каталог вложений задаются переменными из `application.yml`. Сборка и тесты:

```bash
mvn test
```

Flyway применяет схему автоматически. Hibernate работает в режиме `validate` и не изменяет структуру базы самостоятельно.

## Ограничения файлов

К домашнему заданию и материалам занятия можно приложить до 10 файлов размером не более 20 МБ каждый. Исполняемые типы блокируются, а скачивание доступно только преподавателю и ученику, которому принадлежит занятие.
