# RepetHelper brand

`src/main/resources/static/brand/repethelper-mark.svg` — основная монограмма RH.
`repethelper-wordmark.svg` — горизонтальный вариант для презентаций и публикаций.

- Основные цвета: изумруд `#31D98B`, голубой `#38BDF8`.
- Минимальная ширина знака — 24 px; вокруг него оставляйте свободное поле не меньше четверти его ширины.
- Не растягивайте знак, не меняйте пропорции и не добавляйте тени поверх него.
- Для маленьких аватаров используйте только `repethelper-mark.svg`.
